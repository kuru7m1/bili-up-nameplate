# B站 UP 分组铭牌

> Bilibili UP Group Nameplate · `bili-up-nameplate`

在 Bilibili 页面为任意 UP 主显示自定义分组铭牌。分组名称、浮标颜色与标记文字均可配置；全部数据仅保存在本机浏览器，不上传任何信息。

## 功能

- **分组管理**：新建、改名、删除分组；每组独立配置组名、标记（emoji 或短文字）、铭牌文字、浮标颜色与显示状态；分组顺序支持拖动调整。
- **emoji 选择面板**：标记输入框旁的按钮可展开常用 emoji 列表，点击即填入标记框并写入剪贴板；不使用时可折叠。
- **铭牌显示**：以彩色胶囊形式显示于昵称（含等级牌）右侧，不改变页面原有排版；支持「悬停显示」与「一直显示」两种模式。
- **四种添加方式**：
  1. 昵称搜索：调用 Bilibili 公开搜索接口，列出候选（头像、昵称、UID、粉丝数）后选择添加；
  2. UID / 主页链接：支持批量粘贴，自动提取 UID；
  3. 当前页添加：在 UP 主主页直接加入指定分组；
  4. 批量导入：支持 JSON、CSV 与纯 UID 列表，导入后自动补全昵称、头像与粉丝数。
- **一人多组**：同一 UP 主可同时属于多个分组，铭牌按分组顺序并列显示；可设置为仅显示第一枚。
- **名单维护**：支持按粉丝数、昵称、添加时间排序；可在行内追加分组或从当前分组移出；支持跨组搜索。
- **显示范围**：个人主页、动态、动态详情、搜索、视频页、专栏、直播间、其余页面共八类，可逐项启用或关闭。
- **导入导出**：JSON 用于备份与跨设备迁移，CSV 便于在表格软件中查看。
- **本地优先**：全部数据写入 Tampermonkey 的 `GM_setValue`；无服务器、无埋点、无任何上报逻辑。

## 安装

### 1. 安装 Tampermonkey

| 浏览器 | 地址 |
|---|---|
| Chrome | <https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo> |
| Edge | <https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd> |
| Firefox | <https://addons.mozilla.org/firefox/addon/tampermonkey/> |

### 2. 安装本脚本

任选一种：

- **拖拽**：将 `dist/bili-up-nameplate.user.js` 拖入浏览器窗口，Tampermonkey 将弹出安装页。
- **导入**：Tampermonkey 图标 →「管理面板」→「实用工具」→ 底部「导入」，选择该文件。
- **Raw 安装**：打开仓库中的 `dist/bili-up-nameplate.user.js`，点击右上角 `Raw`。

安装完成后返回 Bilibili 页面并刷新一次。

### 3. 打开设置面板

- 点击 Tampermonkey 图标 →「⚙ 打开设置面板」；
- 或在 Tampermonkey 菜单中点击「＋ 把当前 UP 加入分组」。

安装后名单为空，不写入任何分组或成员。如需查看示例效果，可使用「⋯ → ⇩ 导入测试分组」导入内置示例分组；导入后均可修改或删除，其中人数最多的分组默认不显示。

## 使用

### 建组

「⋯ → 新建分组」。组名、铭牌文字、标记与颜色均在分组标题行内配置：

- **颜色**：点击取色器修改浮标底色，修改后页面上的铭牌即时更新；
- **标记**：emoji 或不超过 12 个字符的短文字（如 `🎀`、`VR`），显示于浮标最左侧；点击旁边的 emoji 面板按钮可展开候选列表，选中后填入标记框并写入剪贴板；
- **铭牌文字**：显示于浮标上的文字；留空时使用组名，可用于「组名为全称、浮标显示缩写」的场景；
- **显示**：取消勾选后该组铭牌立即从页面移除，成员名单不受影响；同一 UP 主若仍属于其他分组，其余铭牌照常显示；
- **排序**：按住分组标题左侧的 ⠿ 上下拖动，松手后生效；分组顺序即页面上多枚铭牌的排列顺序。

### 添加成员

面板右上角「＋ 添加 UP」提供三个页签：

| 页签 | 说明 |
|---|---|
| 搜索昵称 | 输入昵称后回车，在结果中点击「加入」；已在本组的显示「已在本组」，已在其他组的显示「＋ 再加一组」，点击后同时属于两个分组 |
| UID / 链接 | 每行一个 UID 或 `space.bilibili.com/12345`，支持粘贴整段分享文案；解析后逐条预览再确认 |
| 批量导入 | 支持拖入文件或粘贴文本，可先预览再导入 |

底部「目标分组」指定本批成员加入的分组；导入数据若自带分组名，将按名称自动建组。

分组列表每行右侧的下拉菜单可将该 UP 主加入其他分组；其所属的其他分组以彩色小块显示于名称之后，点击 ✕ 仅从当前分组移出。

### 导入格式

**JSON**：支持本插件导出的格式，或任意「分组 → 成员」结构：

```json
{
  "groups": [
    {
      "name": "VirtuaReal",
      "badge": "🎀",
      "text": "VR",
      "color": "#7c5cff",
      "members": [{ "uid": 1694351351, "name": "向阳Hihi", "fans": 16765 }]
    }
  ]
}
```

```json
{
  "groups": {
    "PSPLive": {
      "members": [{ "uid": 186463, "biliName": "綾奈奈奈", "followers": 197724 }]
    }
  }
}
```

**CSV / TSV**：表头包含 UID 列与分组列即可识别，列名支持中英文（`UID` / `mid`、`B站现用名` / `昵称` / `name`、`所属团体` / `分组` / `group`、`粉丝数` / `fans`、`标记`、`铭牌文字`、`颜色`）。多分组使用 `全部分组` 列表示，多个组名以 `|` 分隔。

**纯文本**：每行一个 UID 或主页链接，全部归入当前选中的目标分组。

导入按 UID 去重：同一 UP 主在同一分组内不会重复出现；重复导入不会重复添加；同一 UP 主出现在多个分组时，将同时属于这些分组。

### 导出

「⋯ → 导出 JSON / 导出 CSV」。JSON 可重新导入，用于备份或跨设备迁移；一人多组的关系记录于 JSON 的 `memberGroups` 与 CSV 的 `全部分组` 列，重新导入后不会丢失。

## 数据与隐私

- 全部数据保存于 Tampermonkey 存储（键名 `bnp:groups`、`bnp:members`、`bnp:settings`），不写入 Cookie，不上传远端。
- 内置示例名单在构建时确定并写入脚本文件，安装后不为该名单发起任何请求，亦不存在定期同步机制；安装时不会自动导入，仅在点击「⇩ 导入测试分组」时写入本地存储。
- 脚本仅请求三类 Bilibili 公开接口，且仅在用户主动操作时发起：
  - `x/web-interface/nav`：获取 WBI 签名密钥；
  - `x/web-interface/wbi/search/type`：按昵称搜索用户；
  - `x/web-interface/card`：按 UID 获取昵称、头像与粉丝数。
- 不校验登录态、不做行为统计、不请求第三方域名。
- 重装前请勿清除 Tampermonkey 数据；建议定期导出 JSON 备份。

## 关于「搜索昵称」

Bilibili 用户搜索接口要求 WBI 签名（`w_rid` 与 `wts`）。脚本内置不依赖外部库的 MD5 与签名实现，签名密钥从 `nav` 接口获取，有效期 6 小时。

该接口公开但未提供官方文档，因此：

- 可能触发风控（返回 `-412` / `-352`），此时面板会给出提示，并建议改用 UID 添加；
- 请求已限速（最多 3 并发，间隔 110ms）；
- 搜索失败不影响其他三种添加方式。
